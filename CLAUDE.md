# Правила для Claude

Это «Brevet» — приложение для подготовки к бревету по математике (DNB 2027) для учеников владельца (репетитора по математике), которые учатся во Франции и говорят по-русски. Сайт — один файл `index.html`, его отдаёт GitHub Pages из ветки `main`, из корня. Репозиторий **открытый**. Сделан из шаблона `pages-template`; устройство экранов — по образцу приложений «End Term» и «Marta · Maths».

## Как общаться
- По-русски, на «вы», неформально и коротко. Без воды и лишних оговорок.
- Перед большой работой — уточняющие вопросы одним блоком: нумерованный список, у каждого вопроса 2–4 варианта и свой вариант ответа; рекомендуемый пометить «(рекомендую)».
- Не выдумывать факты. Не знаешь — проверь (документация Apple, MDN, GitHub, eduscol) или так и скажи.
- Если владелец неправ — сказать прямо, с доводами.
- В конце ответа — 2–3 пункта, что можно раскрыть подробнее.

## Решения владельца (не менять молча)
- Одно приложение на всех учеников: вход по имени и PIN из 4 цифр (PIN по желанию).
- Интерфейс, подсказки, решения, шпаргалки — по-русски. **Условия заданий — по-французски**, как на экзамене; русский перевод — только кнопкой «Перевод», и **при переключении страница не должна сдвигаться** (французский и русский текст лежат в одной ячейке сетки, см. `bt()` и `.bi`).
- Содержимое — всё сразу: Partie 1 (автоматизмы), Partie 2 (задачи «по мотивам» реальных вариантов: тот же сюжет, другие числа, с указанием источника), пробники с таймером, обоснования тренируются выбором верного обоснования и сборкой решения из шагов.
- Отчёта репетитору нет. Вид — как у «Marta · Maths»: тёплая бумага, тёмно-синий, янтарь, заголовки с засечками.
- Ориентир — бревет 2027: математика 28 июня 2027, 10:00–12:00 (дата в `APP.exam`, `src/js/30-store.js`).
- Сохранность прогресса — главное: сохранение после каждого ответа, копии на устройстве, копия файлом и кодом, загрузка копии только объединяет и сначала показывает, что изменится.
- Работает на любых устройствах (iPhone, iPad, Android, ноутбук), без интернета после первого открытия.
- Приложение с таблицами (tableur) — отдельное («Tableur Brevet», репозиторий Knights), здесь на него только ссылка.

## Как работать
- Каждая правка — своя ветка и PR. Описание PR по-русски: что сделано, как проверено, что посмотреть.
- После «ок» владельца на конкретный PR — смержить его самому (обычный merge в `main`). Сайт обновится через 1–2 минуты, приложения на устройствах подхватят новую версию сами.
- Исходники — в `src/`, `index.html` **собирается**, руками его не править. Перед каждым коммитом:
  1. `python3 tools/build.py` — собрать `index.html` (`--content=00-base` — собрать только с частью заданий, для отладки).
  2. `python3 tools/stamp.py` — обновить метку версии. Без этого приложения на устройствах не узнают о новой версии.
  3. `node tests/engine.js` и `node tests/content.js` — ядро и все задания (`node tests/content.js ge --show=ge.thales` — посмотреть, что генерирует тема).
  4. `node tools/check.js` — вид на iPhone 15 (393×852), iPad mini (744×1133), iPad Pro 11 (834×1194 и 1194×834), светлая и тёмная тема; все темы и задачи на экране; вход и PIN; пробник; самообновление; офлайн. Около 5 минут; `node tools/check.js quick` — быстрее. Скриншоты — в `.work/check/` (в git не попадают), посмотреть их глазами.
- Собранный `index.html` коммитить вместе с исходниками — иначе на сайте ничего не изменится.
- Новые файлы сайта (значки и т. п.) — рядом с `index.html`; список файлов офлайн-копии — `FILES` в `sw.js` (при изменении поднять номер в `CACHE`). Значки рисует `node tools/icons.js`.
- Хранение: ключи `brevet:…` в localStorage (на github.io у всех приложений владельца один адрес — ключи не должны пересекаться). Меняется формат прогресса — поднять `DBV` и дописать `migrate()` в `src/js/30-store.js`, проверить на старой копии.

## Задания
- Как писать задания — `docs/content.md` (формат, API, правила качества). Главное: объяснять причины, а не рецепты; французский — как в бревете; русский перевод естественный; у каждой темы 2–5 типов заданий.
- Все файлы `src/content/*.js` склеиваются в одну область — у имён верхнего уровня приставка файла.
- Реальные варианты бревета (ссылки) — в описании первого PR; тексты заданий дословно в репозиторий не копировать, только «по мотивам».

## Безопасность — репозиторий открытый
- Никаких паролей, ключей, токенов.
- Никаких личных данных учеников: имён, фамилий, телефонов, почты, оценок, фото. Имя ученик вводит сам на своём устройстве. Демо-данные — только вымышленные.
- Данные пользователей живут только на их устройстве (`localStorage`), в репозиторий не попадают.

## Устройство index.html
- В самом начале — `<meta name="app-build" content="ДАТА·ХЭШ">`. Не переносить ниже: приложение скачивает только первые 4 КБ свежего файла и сравнивает метки.
- Самообновление (`src/js/95-boot.js`): при открытии, при возврате и раз в 10 минут. Ученик ничем не занят — перезагрузка сразу; занят (курсор в поле, открыто окно, идёт пробник — `window.appBusy`) — плашка «Обновить».
- Без внешних библиотек и шрифтов из сети: KaTeX и Lora встроены. Шрифт текста — системный. Текст заданий не мельче 15 px, остальное не мельче 12 px, поля ввода не меньше 16 px, кнопки не меньше 44 px.
- Цвета — через переменные в `:root`; тёмная тема задана дважды (по системе и по выбору) — менять оба места.
