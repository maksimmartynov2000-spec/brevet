# Brevet · математика

Приложение для подготовки к бревету по математике (DNB, сессия 2027) для русскоязычных учеников, которые учатся во Франции.
Интерфейс и объяснения — по-русски. Условия заданий — по-французски, как на экзамене: незнакомое слово переводится нажатием, весь текст — кнопкой «Перевод».

**Адрес:** https://maksimmartynov2000-spec.github.io/brevet/ — открыть в Safari → «Поделиться» → «На экран „Домой“». Работает на телефоне, планшете и компьютере, без интернета после первого открытия.

## Экзамен
- Математика — понедельник, 28 июня 2027, 10:00–12:00 (по календарю министерства, который приводят letudiant.fr, nomadeducation.fr и SNES).
- Формат с 2026 года: **Partie 1 — Automatismes** (6 баллов, 20 минут, без калькулятора, 9 коротких вопросов) и **Partie 2 — Raisonnement et résolution de problèmes** (14 баллов, 1 ч 40, с калькулятором; 2 балла из 14 — за ясность изложения).
- Для Partie 1 министерство опубликовало ориентировочный список из 37 автоматизмов — он есть в приложении («Программа → Автоматизмы») с привязкой к темам.

## Что внутри
| Раздел | Что там |
|---|---|
| **Вход** | Имя и PIN из 4 цифр (по желанию). На одном устройстве может быть несколько учеников; если их двое и больше — кнопка «Ученики: обзор» для репетитора. |
| **Сегодня** | Домашнее задание (если задано) — первой карточкой. Цель дня и серия. Кнопка «Заниматься» ведёт по порядку: разминка → домашнее задание → план дня. Отсчёт до бревета и готовность, работа над ошибками, напоминание отправить код. |
| **Программа** | Главы программы cycle 4, поиск темы или задачи по-русски и по-французски. В главе: темы двух уровней (база → бревет), задачи Partie 2 «по мотивам» реальных вариантов, шпаргалка с точными французскими формулировками. Список автоматизмов министерства, словарик терминов, ссылка на тренажёр Tableur Brevet. |
| **Тренировка** | Бесконечные задания по теме с новыми числами: проверка с объяснением ошибки, 1–3 подсказки, разбор решения с причинами. Тихий секундомер; на заданиях без калькулятора — отметка «дольше 2 минут». |
| **Задача Partie 2** | Контекст, рисунок и 3–6 вопросов, в том числе «на рассуждение» (выбрать верное обоснование, расставить шаги). В решении каждого вопроса — «Как записать на экзамене»: образец записи по-французски. |
| **Пробники** | Partie 1 (20 мин), Partie 2 (1 ч 40), Brevet blanc (2 ч), Экспресс (10 мин), Стартовая проверка. В пробниках нет ни перевода, ни подсказок по словам — как на экзамене; в разборе после пробника они есть. |
| **Мои слова** | Французские слова, перевод которых ученик смотрел в заданиях. Повторение карточками через 1, 4 и 14 дней. |
| **Я** | Статистика, график за 2 недели, готовность и её изменение за неделю, план, значки, настройки, данные и копии, «Репетитору». |

## Как идёт подготовка
- **Освоение.** Три верных ответа подряд с первой попытки — тема освоена.
- **Повторение.** Освоенная тема возвращается одним заданием через 3, 10 и 30 дней (дальше — раз в 30 дней). Ответ верный — следующий срок. Ошибка в повторении возвращает тему в работу: снова три верных подряд. Ошибка в освоенной теме вне повторения (в смешанном наборе, в пробнике) освоения не отнимает, но тема придёт в ближайшую разминку.
- **Разминка.** Каждый день — 5 коротких вопросов без калькулятора, как в Partie 1: сначала темы, которым пора повториться, потом темы с недавними ошибками, потом давно не встречавшиеся. Только то, чем ученик уже занимался.
- **План дня.** База раньше уровня бревета, главы по очереди; повторения тем с калькулятором и тема с недавними ошибками идут первыми. Репетитор управляет порядком через домашнее задание.
- **Готовность** = 50 % освоенные темы + 25 % задачи Partie 2 + 25 % последний пробник.

## Французский язык
Ученики говорят по-русски, французский учат, а экзамен — на французском. Поэтому:
- условие всегда по-французски; **нажатие на слово** показывает перевод рядом (для выражений вроде «au moins» или «par rapport à» — перевод выражения целиком). В кнопках с вариантами ответа — долгое нажатие или правая кнопка мыши;
- кнопка **«Перевод»** показывает весь текст по-русски на месте французского (страница не сдвигается) и действует на одно задание: следующее снова по-французски. Приложение считает, как часто ученик ею пользуется;
- слова, перевод которых ученик смотрел, собираются в **«Мои слова»**;
- в задачах Partie 2 — образец записи решения по-французски, в шпаргалках — точные формулировки теорем («D'après le théorème de Pythagore…»);
- каждое французское слово каждого условия есть в словаре приложения — это проверяет тест (`node tests/content.js --lex`).

Французские тексты писал и перепроверял ИИ (отдельными независимыми проходами), носитель языка их не вычитывал. Найденную ошибку можно отправить из разбора любого задания: «Нашёл ошибку в задании? Сообщить».

## Репетитору
Всё работает без сервера: устройство репетитора знает об ученике из его кода прогресса.
- **Обмен кодом.** Перед уроком ученик присылает код, репетитор вставляет его у себя и занимается в профиле ученика; после урока отправляет код обратно.
- **Домашнее задание** («Я → Репетитору»): темы (сколько заданий), задачи Partie 2, пробники; готовый набор на 10–15 минут или свой; срок по желанию. Задание уезжает к ученику в коде и встаёт первым на «Сегодня». Когда всё сделано, приложение предлагает ученику отправить код — репетитор видит результат.
- **Ученики: обзор** (экран входа): по каждому ученику — готовность и её изменение за неделю, занятия за 7 и 30 дней, темп (успевает ли пройти темы до экзамена), трудные и медленные темы, как часто нужен перевод, пробники, домашнее задание.
- **Сводка для родителей** — текст за неделю или месяц, только факты из приложения.
- **Режим урока** — для показа экрана в Zoom: условие по-французски и по-русски рядом, крупнее, решение открывается по шагам.
- **Печать и PDF**: лист по теме, смешанный лист, вариант Partie 1, задача Partie 2, Brevet blanc. Лист для ученика — только по-французски, с местом для решения; ответы — отдельным документом (только ответы или с решениями, перевод условий по желанию). Лист можно открыть снова по ссылке — числа останутся те же. Печать — средствами браузера: «Печать» → «Сохранить как PDF».

## Данные ученика
- Прогресс хранится **только на устройстве** (localStorage, ключи `brevet:…`) и сохраняется после каждого ответа. В репозиторий ничего не попадает.
- Раз в день приложение само делает копию на устройстве (хранятся 3 последние; копия делается также перед каждой загрузкой кода и перед переходом на новый формат прогресса) — «Я → Данные и копии» → вернуть.
- **Код прогресса** (`BRV3.…`) — короткий текст со всем прогрессом и домашним заданием. Год занятий помещается в одно сообщение Telegram (< 4096 знаков; проверяет `tests/backup.js`).
  - В коде: состояние каждой темы и задачи (попытки, последние ответы, освоение, срок повторения, обычное время на задание), последние 5 недель по дням (более раннее — одной суммой), последние 12 пробников, значки, 30 слов из «Моих слов», домашнее задание и три прошлых, готовность сейчас, неделю и месяц назад.
  - Загрузка кода сначала показывает «сейчас / в коде» и сохраняет текущее состояние копией. Потом прогресс **объединяется**: по каждой теме остаётся то состояние, которое новее; счёт решённого не уменьшается.
  - Коды первой версии (`BRV2.…`) и файлы копий по-прежнему читаются.
- Приложение честно пишет, что прогресс хранится только на этом устройстве. Первое напоминание отправить код — после 10 заданий, дальше — раз в неделю и после выполненного домашнего задания.
- Запасной способ — копия файлом.
- На iPhone приложение с экрана «Домой» хранит данные отдельно от Safari, а Safari стирает данные сайтов, которые не открывали 7 дней. Поэтому при первом запуске в Safari приложение предлагает сначала установить его на экран «Домой».

## Как устроено
Сайт — один файл `index.html`, его отдаёт GitHub Pages. Он **собирается** из исходников в `src/`:

| Путь | Что |
|---|---|
| `src/page.html` | каркас страницы |
| `src/style.css` | стили (палитра «тихая тетрадь»: тёплая бумага, тёмно-синий, янтарь; светлая и тёмная тема; печать) |
| `src/vendor/` | KaTeX 0.16 (формулы) и шрифт Lora для заголовков — встроены в файл, сеть не нужна |
| `src/js/00–28` | ядро: разбор и проверка ответов, генераторы, API контента, формулы в тексте, словарь слов, даты |
| `src/content/*.js` | **задания**: главы, темы, задачи Partie 2, шпаргалки, официальный список, словарь (как писать — `docs/content.md`) |
| `src/content/00-ids.js` | постоянные номера тем и задач для кода прогресса (ведёт `tools/ids.js`, только дописывается) |
| `src/js/30–32` | хранение, копии, формат прогресса и его обновление, код прогресса |
| `src/js/40–95` | экраны: тренировка, слова, домашнее задание, пробники, экраны репетитора, печать, самообновление |
| `sw.js` | работа без интернета |

Команды:
```
node tools/ids.js           # выдать постоянные номера новым темам и задачам (перед сборкой)
python3 tools/build.py      # собрать index.html
python3 tools/stamp.py      # метка версии (без неё устройства не узнают об обновлении)
node tests/engine.js        # проверка ядра: как читаются ответы
node tests/backup.js        # код прогресса: помещается в сообщение, объединение копий, старые коды, обновление формата
node tests/content.js --lex # все задания: ключи принимаются, формулы рисуются, переводы и запись решения на месте, слова есть в словаре
node tests/words.js         # какие французские слова ещё не в словаре
node tools/check.js         # вид на 6 размерах экрана (обе темы), все задания на экране, обучение, обмен кодом, ДЗ, репетитор, печать, самообновление, офлайн
```
