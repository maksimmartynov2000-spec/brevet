# Brevet · математика

Приложение для подготовки к бревету по математике (DNB, сессия 2027) для русскоязычных учеников, которые учатся во Франции.
Интерфейс по-русски, условия заданий — по-французски, как на экзамене, перевод — кнопкой «Перевод».

**Адрес:** https://maksimmartynov2000-spec.github.io/brevet/ — открыть в Safari → «Поделиться» → «На экран „Домой“».

## Экзамен
- Математика — понедельник, 28 июня 2027, 10:00–12:00 (по календарю министерства, который приводят letudiant.fr, nomadeducation.fr и SNES).
- Формат с 2026 года: **Partie 1 — Automatismes** (6 баллов, 20 минут, без калькулятора, короткие ответы и QCM) и **Partie 2 — Raisonnement et résolution de problèmes** (14 баллов, 1 ч 40, с калькулятором; 2 балла из 14 — за ясность изложения).

## Что внутри
| Раздел | Что там |
|---|---|
| **Вход** | Имя и PIN из 4 цифр (по желанию). На одном устройстве может быть несколько учеников. |
| **Сегодня** | Цель дня, серия дней, план на сегодня, отсчёт до бревета и готовность, стартовая проверка, работа над ошибками, напоминание сохранить копию. |
| **Программа** | 8 глав программы cycle 4. В главе: темы по уровням (база → бревет → сверх), задачи Partie 2 «по мотивам» реальных вариантов, шпаргалка. Словарик FR → RU, ссылка на тренажёр Tableur Brevet. |
| **Тренировка** | Бесконечные задания по теме: ввод с математической клавиатуры, проверка с объяснением ошибки, 1–3 подсказки, разбор решения. Три верных ответа подряд — тема освоена. |
| **Задача Partie 2** | Контекст, рисунок и 3–6 вопросов по нарастанию, в том числе «на рассуждение»: выбрать верное обоснование или расставить шаги решения по порядку. |
| **Пробники** | Partie 1 (20 мин), Partie 2 (1 ч 40), Brevet blanc (2 ч, Partie 1 сдаётся и закрывается, как на экзамене), Экспресс (10 мин), Стартовая проверка. Таймер идёт и при закрытом приложении. Оценка /20 и разбор. |
| **Я** | Статистика, график за 2 недели, план до бревета, значки, настройки, данные и копии. |

## Данные ученика
- Прогресс хранится **только на устройстве** (localStorage, ключи `brevet:…`) и сохраняется после каждого ответа. В репозиторий ничего не попадает.
- Раз в день приложение само делает копию на устройстве (хранятся 3 последние и копия перед каждой загрузкой) — «Я → Данные и копии» → вернуть.
- **Копия файлом** или **кодом для переноса** — на случай потери телефона и для переноса на другое устройство. Загрузка копии сначала показывает, что изменится, сохраняет текущее состояние отдельной копией и **объединяет** прогресс (по каждой теме — лучший результат), а не затирает.
- Раз в неделю приложение напоминает сохранить копию.
- На iPhone приложение с экрана «Домой» хранит данные отдельно от Safari, а Safari стирает данные сайтов, которые не открывали 7 дней. Поэтому при первом запуске в Safari приложение предлагает сначала установить его на экран «Домой».

## Как устроено
Сайт — один файл `index.html`, его отдаёт GitHub Pages. Он **собирается** из исходников в `src/`:

| Путь | Что |
|---|---|
| `src/page.html` | каркас страницы |
| `src/style.css` | стили (палитра «тихая тетрадь»: тёплая бумага, тёмно-синий, янтарь; светлая и тёмная тема) |
| `src/vendor/` | KaTeX 0.16 (формулы) и шрифт Lora для заголовков — встроены в файл, сеть не нужна |
| `src/js/00–25` | ядро: разбор и проверка ответов, генераторы, API контента, формулы в тексте |
| `src/content/*.js` | **задания**: главы, темы, задачи Partie 2, шпаргалки, словарь (как писать — `docs/content.md`) |
| `src/js/30–95` | приложение: хранение и копии, экраны, тренировка, пробники, самообновление |
| `sw.js` | работа без интернета |

Команды:
```
python3 tools/build.py      # собрать index.html
python3 tools/stamp.py      # метка версии (без неё устройства не узнают об обновлении)
node tests/engine.js        # проверка ядра: как читаются ответы
node tests/content.js       # все задания: ключи принимаются, формулы рисуются, переводы на месте
node tools/check.js         # вид на iPhone 15 и iPad (обе темы), все темы на экране, вход, пробник, самообновление, офлайн
```
